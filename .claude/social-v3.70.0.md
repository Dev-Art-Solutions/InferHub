# v3.70.0 social copy (unposted)

## Facebook

InferHub 3.70 answers a question you used to find out the hard way: how close am I to the limit?

The console now has a Provider limits panel. For every cloud provider — the coordinator's own and each node's own — it shows:
• a ChatGPT sign-in: how much of the five-hour and the weekly window is used, and when each resets
• an OpenAI or Anthropic key: requests and tokens per minute
• this month's spend against a budget you set
• the vendor's last "no", in its own words

It only shows what the vendor said. No guessed bills.

And a box with no GPU can now make video: Google's Veo and Gemini Omni, through the same /v1/videos routes a GPU node answers. (There's no OpenAI video — Sora was shut down in September.)
