# InferHub v3.69.0 — social copy (unposted)

## Facebook

InferHub 3.69: pictures, voices and transcripts from OpenAI and Google.

A coordinator or a node with no GPU can now make pictures, speak text and transcribe audio through OpenAI or Google with an API key — on the same routes a GPU node answers.

• The coordinator gets a Media map on its OpenAI or Gemini provider; a node gets its own section and its own key.
• By default a vendor answers only when no node offers that model, and a failed vendor call is never retried on a node.
• What a vendor would get wrong — a negative prompt, a Gemini mp3 voice, an unsupported size — is refused before anything is sent.
• A ChatGPT sign-in can read pictures in a chat, but OpenAI doesn't allow it to make them.
