## Facebook

InferHub 3.115: paste a link to a picture model and the node answers from its recipes. If a recipe already names the repository, that is the answer. If it is a fine-tune of a pipeline a recipe runs, the node writes a recipe from that one, with the fine-tune's own commit, licence and weights. If no recipe runs it, the node says so.

It never runs code from the repository and loads safetensors only. On an RTX 3090 Ti, Dreamshaper 8 went from a link to a picture, and the card used 3.4 GB against the 4 GB the recipe allows.
