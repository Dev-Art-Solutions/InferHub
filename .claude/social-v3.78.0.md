# v3.78.0 social copy (unposted)

## Facebook

InferHub 3.78: the big model is mine, the small one may serve anybody.

In a network of friends' PCs, a machine often holds one big model its owner uses for their own work and a few small ones that cost little to lend. A node can now keep some models to itself. It never tells the network they are there, so no coordinator of any version routes to them. The owner's own apps still use them through the node's local API.

The change reaches the network within a second, with no restart. InferHub Desktop 0.3.0 puts a "Shared" box beside each model.

https://blog.devart.solutions/blog/inferhub-3-78-models-kept-for-the-owner
