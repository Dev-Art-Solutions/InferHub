## Facebook

InferHub 3.76: a node of your own, and an app to run it.

When friends pool their machines into one network, every machine is still somebody's computer. So a node now has its own control panel. You can see what it is doing, change its settings, restart it and manage its models, all on the box, with no coordinator needed.

Set it to share only when you are not using it, and the network goes around it while you work. Keep documents on it that the network never sees.

And there is InferHub Desktop 0.1.0, for Windows, Linux and macOS. It attaches to the node on your machine, or runs its own, with nothing else to install.
