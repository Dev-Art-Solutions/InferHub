## Facebook

InferHub 3.81: models from the coordinator, on the owner's terms.

A node on a far-away VM has nobody sitting at it. Its coordinator can now do what the desktop app does on it: browse what is trending on Hugging Face and in Ollama's library, ordered by what fits that machine, check a model at the context you choose, and install it there.

It can do this only where the node's owner said yes at install, and only within the disk the owner allowed: a largest model, and a floor of free space. The node decides each request itself, and a change to the owner's settings applies with no restart.

Found on the way: every test passed, and the console still listed every node as "older than 3.81". Opening it in a browser found that; the tests only called the API.
