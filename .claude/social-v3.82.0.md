## Facebook

InferHub 3.82: a sealed node.

Set one key on a node, Node:Sealed, and it reaches nothing outside its own network except its coordinator. It will not start with any way out left open: a cloud engine, its own API on a public address, a download it would make by itself. It names every one of them in a single error, so you fix the config in one edit.

What it still needs, it gets through the coordinator. An Ollama pull, a Hugging Face file, the model catalogue and Check fit all go through a relay on the hub. The hub fetches them and streams them down, ranges included. Its Ollama's cloud models and web search are switched off, and if you started that Ollama yourself, the node hides its cloud models and refuses them.

Found before writing any C#: Ollama takes a blob only from a redirect to a different host. So the node's one-pull registry answers on 127.0.0.1 and redirects to localhost, the same listener under a second name.
