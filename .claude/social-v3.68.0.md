# InferHub v3.68.0 — social copy (unposted)

## Facebook

InferHub 3.68: sign in with ChatGPT.

The coordinator and each node can now run requests on a ChatGPT plan after a browser sign-in — no API key, no separate bill.

• The coordinator and a node sign in separately, as their own accounts. The coordinator never gets a node's tokens.
• A remote coordinator is signed in from the browser on your own computer, with a one-time pairing code and a small helper.
• It never falls back to a paid API. Without the plan permission, requests are refused with a reason.
• Tokens are encrypted on disk and never shown in the console, the status page or a log.

The existing OpenAI provider with an API key is unchanged.
