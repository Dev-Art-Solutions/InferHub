## Facebook

InferHub 3.85: who asked, and which node answered.

A coordinator can now keep an audit trail. One line per request: which key, from where, which model, how long it took, and every node the request was sent to, in order. One line per node that joined, was turned away for a wrong secret, or left. Never the prompt, the answer, a query string or a key.

Live: a node was stopped in the middle of a long answer, another node finished it, and the line named both. A search of the files for the prompts and the keys found nothing.
