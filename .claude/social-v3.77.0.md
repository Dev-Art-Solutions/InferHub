# v3.77.0 social copy (unposted)

## Facebook

InferHub 3.77: your GPU at night, not while you work.

In a network of friends' PCs, each machine is still somebody's computer. A node can now say when it shares ("mon-fri 18:00-08:00", "weekends all day") and how many minutes of other people's work it does in a day. Outside those hours, or once the minutes are used, the network goes around it. A job already running still finishes, and your own work never counts.

Running it found a bug. The hub had been telling everyone that a node its owner paused had a broken inference server. Now it gives the owner's reason and says when to try again.

InferHub Desktop 0.2.0 lets you set all of this from the app.

https://blog.devart.solutions/blog/inferhub-3-77-sharing-on-the-owners-terms

## X

InferHub 3.77: a node shares on its owner's terms. You set the hours ("mon-fri 18:00-08:00") and a daily allowance of network minutes. Restarting the node doesn't reset the allowance. The hub now names the owner's reason instead of blaming the backend. Desktop 0.2.0 edits it all.
