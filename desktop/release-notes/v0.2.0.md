# InferHub Desktop 0.2.0

Sharing hours and a daily allowance (node phase 116). It needs a node at **3.77 or later**. The node in every
package is 3.77.0.

## What is new

- **Sharing hours and a daily allowance**, on the Overview tab:
  - **Hours**, one window per line: `mon-fri 18:00-08:00`, `weekends all day`, `daily 22:00-07:00`. Leave it empty
    to share at any hour.
  - **Time zone**: for example `Europe/Sofia`. Leave it empty to use the node's machine zone.
  - **Minutes a day**: how much network work the node does in a day. `0` means no limit.

  A line above the editor says which hours apply and how much of today's allowance the network has used. Outside
  the hours, or once the minutes are gone, the node takes no new network jobs. A job that is already running
  finishes, and your own work never counts. The node checks the hours before it saves them. If a line is wrong, the
  status bar shows the node's reason.
- When the node pauses for one of these terms, the Overview's sharing line says why, and when it shares again.

## Not signed

Still unsigned. **Windows** SmartScreen: *More info → Run anyway*. **macOS**: right-click `InferHub.app` → *Open* →
*Open*, or `xattr -dr com.apple.quarantine InferHub.app`.
