# InferHub Desktop 0.5.0

Browse models (node phase 119). It needs a node at **3.80 or later**. The node in every package is 3.80.0.

## What is new

- **Browse models…** beside Check fit on the Models tab. It lists what is trending and popular on Hugging Face and
  in Ollama's library, with what fits this machine first: on the card, card + RAM, RAM, size unknown, too big.
- Choose the source (all, Hugging Face, Ollama), the order (trending, downloads, newest), the kind (text, or vision
  for models that also read pictures), a search, and **fits only**.
- Each row shows where the model's weights would sit and how big they are, its downloads or pulls, when it was
  updated, and the node's reason. A box lists its other sizes (Ollama's sizes, or a repository's quants), each with
  its own class.
- **Check fit…** on a row opens the Check fit dialog on that size. That is where you choose the context and install.
  Nothing downloads from the list itself.
- If one source does not answer, it shows as a red line above the list, and the other is still listed.

## Not signed

Still unsigned. **Windows** SmartScreen: *More info → Run anyway*. **macOS**: right-click `InferHub.app` → *Open* →
*Open*, or `xattr -dr com.apple.quarantine InferHub.app`.

## Not established

On Windows the app, built from source, was attached to a 3.80 node running Ollama and a Vulkan llama.cpp, and the
dialog was rendered from that node's live answer. **Check fit… was not clicked in the window**; the same link was
sent to the node's `/fit` with `curl`. The Linux and macOS packages are still built by CI only.
