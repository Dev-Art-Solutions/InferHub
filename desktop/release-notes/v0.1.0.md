# InferHub Desktop 0.1.0

The first release of InferHub Desktop: a control panel for one InferHub node, for Windows, Linux and macOS. It
needs a node at **3.76 or later**, the version that has the control API.

## What it does

- **Attaches to the node on this machine.** The Windows service, a systemd unit, a node in a console: the app finds
  its control token and connects. The Windows service's token is readable by administrators only; the app asks you
  to paste it (`C:\ProgramData\InferHub\Node\control.token`, opened as administrator) rather than widening the file.
- **Or runs its own.** Every package carries a self-contained node (`node/` beside the app). The app starts it on
  loopback with its data in your profile, restarts it when it asks to be restarted, and stops it when you quit.
  Closing the window keeps it in the tray.
- **Tabs:** Overview (state, network connection, engines, limits, sharing), Activity (jobs now and recent — kind,
  model, local or network; never a prompt), Models (pull, warm, unload, delete — delete asks first), Settings (the
  node's editable keys, checked by the node before they are saved; says which need a restart), Logs (live), Chat
  (any model the node serves), Connection (a node on another machine, or joining a network).
- **Sharing from the tray:** share with the network · share when I am not using it · pause sharing.

## Packages

| File | For |
|---|---|
| `InferHub-Desktop-0.1.0-windows-x64.zip` | Windows 10/11, x64. Unzip anywhere, run `InferHub.Desktop.exe`. |
| `InferHub-Desktop-0.1.0-linux-x64.tar.gz` | Linux x64 with a desktop (X11 or Wayland via XWayland). Run `InferHub-Desktop/InferHub.Desktop`. |
| `InferHub-Desktop-0.1.0-macos-arm64.zip` | macOS 12+, Apple silicon. `InferHub.app`. |
| `InferHub-Desktop-0.1.0-macos-x64.zip` | macOS 12+, Intel. `InferHub.app`. |
| `SHA256SUMS.txt` | checksums of the four. |

Nothing else to install: the app and its node are self-contained, .NET included.

## Not signed

The packages are not code-signed. **Windows** SmartScreen says "Windows protected your PC": *More info → Run anyway*.
**macOS** Gatekeeper refuses an app from an unidentified developer: right-click `InferHub.app` → *Open* → *Open*, or
`xattr -dr com.apple.quarantine InferHub.app`.

## Not established

On Windows the app was run with its own node: it attached, a pause took effect live, a restart from the app came
back in 8 s. **Attaching to an installed Windows service was not tried live**; the path is the same client with a
pasted token.
**The Linux and macOS packages are built by CI and were not run on a desktop before this release.** On Linux the tray
icon needs a desktop with StatusNotifier support (KDE, GNOME with the AppIndicator extension).
