# InferHub Desktop 0.3.0

Models kept for this machine (node phase 117). It needs a node at **3.78 or later**. The node in every package is
3.78.0.

## What is new

- **A Shared box beside each model** on the Models tab. Clear the box to keep a model for this machine. Your own
  apps still use it through the node's local API, and the network is not told it is there. Tick the box to give
  the model back. The change reaches the network's coordinator within about a second.
  - If you (or a config file) set an `Include` list, meaning "share only these", the box adds names to it and
    removes them. Unticking the last name is refused, because an empty list means every model. To share nothing,
    pause sharing on the Overview tab.
  - Otherwise the box keeps a model by excluding it, so a model you pull later is still shared, as before.
- The Overview tab says which models are kept: "Kept for this machine: qwen3:32b — the network may use 2 of 3
  models".
- A model the node does not serve at all (left out by `Node:Models`) has no box. Against a 3.77 node there are no
  boxes either.

## Not signed

Still unsigned. **Windows** SmartScreen: *More info → Run anyway*. **macOS**: right-click `InferHub.app` → *Open* →
*Open*, or `xattr -dr com.apple.quarantine InferHub.app`.

## Not established

On Windows the app, built from source, was attached to a 3.78 node running on the real Ollama. The boxes and the
Overview line were drawn from that node's live status. **The box itself was not clicked live.** The request it
sends was sent to the same node with `curl` and applied, and the box's logic is unit-tested. The Linux and macOS
packages are still built by CI only.
